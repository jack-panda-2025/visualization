Plan and progress (pipeline prototype)

Status: Prototype created and initial validation started.

What has been implemented so far
- scripts/export_pipeline.py: prototype exporter that creates progressive gzipped binary chunks (coarse/medium/fine) for the first 5 d3plot* files and writes bin_output_v3/metadata.json.
- server/: minimal Express server (server/server.js) exposing /api/metadata and /api/frame to serve gzipped chunks; package.json included.
- frontend/: minimal static viewer (index.html) that loads /api/metadata and allows fetching each level for inspection.
- bin_output_v3/metadata.json: generated by running the exporter on local d3plot* files.

How to run current prototype locally
- Generate progressive chunks (already run in prototype):
  python3 scripts/export_pipeline.py
- Start server:
  npm --prefix server install
  npm --prefix server start
- Open viewer:
  http://localhost:3001/
